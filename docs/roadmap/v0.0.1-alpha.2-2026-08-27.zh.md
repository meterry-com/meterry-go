# v0.0.1-alpha.1 路线图

日期：2026-08-27

## 本次版本目标

- 将 project 维度的实时 usage-control 查询切换到 `subject/realtime/limits`。
- 保留旧的 wallet-limits snapshot 入口，确保现有调用可以平滑迁移。
- 补齐类型定义与测试，保证公开 JSON 只暴露稳定字段。

## 变更记录

- 新增 `ManagerClient.ReadSubjectRealtimeLimitsForProject`，对应 `/v1/projects/:project_id/subject/realtime/limits`。
- 新增 `types.SubjectRealtimeLimitsSnapshot` 和 `types.SubjectRealtimeLimitItem`。
- `ReadVirtualWalletLimitsForProject` 改为基于 subject realtime limits 数据源返回旧版 snapshot 形状。
- 新增 `ReadRealtimeWalletLimitsForProject` 作为兼容别名，便于逐步迁移。
- `ReadVirtualWalletAmountForProject` 保持不变，继续作为 realtime balance 查询入口。
- README 补充了新 helper 的使用说明和弃用提示。
- 测试覆盖新增 endpoint、兼容映射和公开字段红线。

## 兼容性说明

- 旧的 wallet limits 查询逻辑仍可用，但建议逐步迁移到 `ReadSubjectRealtimeLimitsForProject`。
- `ReadVirtualWalletLimitsForProject` 和 `ReadRealtimeWalletLimitsForProject` 当前都返回同一套兼容数据结构。
- subject realtime limits 不再重复返回 wallet amount。

## 后续规划

- 逐步收敛调用方到 `ReadSubjectRealtimeLimitsForProject`。
- 后续版本再评估是否移除旧的 wallet-limits 兼容包装。
